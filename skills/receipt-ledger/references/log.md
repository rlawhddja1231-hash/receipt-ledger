# 영수증 장부 — 시험 기록

## 2026-10-25 처음 만듦 [도구 시험]

시험 파일(모두 가짜): 카드영수증 사진(기울어짐), 현금 김밥집 영수증(합계만), 흐리고 점 많은 감열지 영수증(6도 기울어짐), 사업자번호 한 자리가 틀린 주유 영수증, 현금영수증, 같은 카페 영수증을 다시 찍은 사진, 전자세금계산서 PDF(표 모양), 면세 계산서 PDF, 글자 없는 스캔 거래명세서 PDF, 카드 승인 문자 4건(끝 4자리 없는 현대카드, 취소 1건 포함).

순서대로 해 봄: 준비 → 내가 그림을 보고 입력.json 채움 → 검사 → 장부.
- 준비: PDF 2개는 글에서 초안을 채움(세금계산서의 '머리 줄 아래 값 줄' 표, 24자리 승인번호 포함). 사진·스캔 7개는 그림으로.
  - 고친 것: 표 모양 세금계산서에서 공급가액·세액을 못 찾았다 → 머리 줄·값 줄 짝 맞추기. 상호에 공급받는자 상호가 붙어 나왔다 → 나눔. 끝 4자리 없는 카드 문자를 놓쳤다 → 읽음.
  - 고친 것: 흐린 영수증의 '선명' 그림이 거의 그대로였다(배경 때문에 대비가 안 늘어남) → 종이 밝기를 기준으로 대비를 늘리게 바꿈. 바꾼 뒤 글자가 또렷하게 읽힘.
- 내가 읽기: 7장 모두 읽음. 흐린 영수증은 금액이 이름표 한 줄 위에 찍혀 있었는데 공급가액+부가세=합계로 맞춰 바로잡음.
- 검사: 틀린 사업자번호(검사 숫자) 1건 ✗, 흐린 영수증 1건 !, 중복 4건(다시 찍은 사진 1, 카드 문자와 영수증 3) 모두 잡음.
- 장부: 9건, 합계 1,927,000원 — 손으로 더한 값과 같음. LibreOffice로 열어 색·숫자 모양·인쇄 폭 확인.
- 이어 쓰기: 지난 장부 9건 + 새 2건 중 이미 있던 1건은 뺌.

## 2026-10-25 다른 검사 담당의 시험 [도구 시험]

만든 사람이 아닌 검사 담당이 까다로운 PDF 13개, 카드 문자 9개, 입력 파일 20여 개, 사람이 고친 장부로 시험. 잘 된 것: 합계 시트끼리 맞음, 취소는 마이너스, BOM, '1,500,000원정', 수정세금계산서 마이너스. 찾은 것과 고친 것:
- **같은 카페·같은 날·같은 금액의 진짜 두 거래를 중복으로 지웠다** → 승인번호가 서로 다르면 다른 거래로 봄.
- 환불이 플러스가 됐다(₩-3,000, '−' 다른 빼기 글자) → 마이너스. '1.100.000' 읽음. '1e5'·{…} 같은 이상한 값은 못 읽음으로.
- 지난 장부 이어 쓰기: 번호 없이 사람이 넣은 줄이 사라졌다, '=2000+2500' 계산식이 빈칸, '총계' 줄이 거래로 들어왔다, 칸이 다른 장부를 0건으로 읽고 덮을 수 있었다 → 모두 고침(칸 이름이 다르면 멈추고 알림).
- 공급받는자가 먼저 나온 세금계산서에서 사는 쪽 상호·번호를 잡았다 → '공급자/공급받는자' 이름표를 따라 파는 쪽을 고름. '(법인명)' 글자 뺌.
- 카드 문자 9개 중 3개를 말없이 놓쳤다(날짜가 금액 앞, 해외 USD, 빈 줄 없이 붙은 문자) → 모두 읽음, 못 읽은 문자는 개수와 내용을 알려 줌. 할부 개월은 메모에.
- 50쪽짜리 세금계산서 묶음 PDF가 1건이 됐다 → 쪽마다 따로 된 증빙이면 쪽마다 1건.
- '포인트 누적 합계'를 합계로 잡았다 → 포인트·누적·잔액·받은 금액 줄은 합계에서 뺌.
- 꺼낸 글 파일과 메모에 카드번호 16자리가 그대로 남았다 → 끝 4자리만.
- 멈춤 여러 곳(상호가 숫자·목록, NaN, UTF-16 입력, 없는 지난 장부, CSV 장부) → 쉬운 말로 알림. `{"거래": []}` 가 가짜 1건이 되던 것 고침.
- 세금계산서인데 합계만 있으면 '확인'으로 표시. 부가세 시트에 종류 없는 거래·합계 줄 더함. 연도 없는 12/30을 10월에 읽으면 작년으로. 열기 암호 PDF·읽을 수 없는 그림은 '읽을 수 없는 파일'로 따로 알림. 큰 사진(2억 화소)도 엶.

아직 못 한 것: **실제 영수증 사진으로 해 보기.** 사용자가 처음 써 보면 결과를 여기 적는다.
