# 영수증 장부

영수증과 세금계산서를 엑셀 장부로 만든다. **읽기는 내가 그림을 직접 보고 하고, 도구(`scripts/rledger.py`)는 준비·검사·장부 만들기를 한다.** 속은 openpyxl(MIT), pypdf(BSD), pypdfium2(Apache-2.0/BSD), Pillow(HPND)다.

근거 등급: **[도구 시험]** 직접 만든 가짜 영수증·세금계산서로 처음부터 끝까지 돌려 본 것(2026-10-25) / **[확인]** 실제 사용자 영수증으로 해 본 것(날짜를 적는다) / **[추정]** 내 짐작.

---

## 0. 말하는 법과 지킬 것

- 쉬운 한국어로 말한다. 물을 것은 선택지로 하나씩 묻고, 추천 하나와 이유 한 줄을 붙인다. 도구 이름·명령어·영어는 말하지 않는다.
- 사용자가 질문하면 되묻지 말고 먼저 답한다.
- **안 보이는 숫자를 지어내지 않는다.** 흐려서 안 읽히는 칸은 비워 두고 `확신: 낮음`, 메모에 "흐려서 못 읽음"을 적는다. 비어 있는 칸은 장부에서 빨강·노랑으로 드러난다.
- **카드번호는 끝 4자리만 적는다.** 영수증에 전체 번호가 보여도 장부·채팅에 옮기지 않는다. 주민번호·계좌번호도 적지 않는다.
- **세금 판단은 하지 않는다.** "공제된다/안 된다", "경비 처리 된다"는 말하지 않는다. 계정과목은 짐작이라고 밝히고, 부가세 시트는 증빙별 합계일 뿐이라고 말한다. 신고는 세무사나 홈택스 기준으로 확인하라고 한다.
- 중복으로 보이는 거래는 내가 마음대로 지우지 않는다. 먼저 보여 주고 뺄지 묻는다.
- 결과 엑셀은 전체를 한 번에 준다(SendUserFile). 원본 사진·PDF는 건드리지 않는다.

## 1. 할 수 있는 것과 못 하는 것

**할 수 있는 것** [도구 시험]
- **준비**: 폴더째로 받는다. 사진(jpg·png·webp·heic*)은 방향을 바로 세우고 크기를 맞춘 그림과, 흐린 감열지용 **선명하게 한 흑백 그림**을 따로 만든다. PDF는 글자를 꺼내고 쪽마다 그림을 만든다(글자 없는 스캔 PDF도 그림으로). 카드 승인 문자 .txt는 문자마다 한 건으로 자동으로 채운다.
- **글에서 초안 채우기**(글자 있는 PDF·문자): 종류, 날짜, 상호, 사업자번호, 공급가액·부가세·합계(같은 줄이든 '머리 줄 아래 값 줄' 표든), 승인번호(전자세금계산서 24자리 포함), 카드 끝 4자리, 결제수단. **초안은 반드시 그림과 견줘 확인한다.**
- **카드 문자**: 신한·KB국민·삼성·현대·롯데·하나·우리·BC·NH농협 등, 끝 4자리 있어도 없어도, 취소는 마이너스.
- **검사**: 날짜 없음·없는 날짜·오늘보다 뒤, 합계 없음, 사업자번호 자리 수·검사 숫자(잘못 읽은 숫자를 거의 다 잡는다), 세금계산서인데 사업자번호 없음, 공급가액+부가세≠합계, 부가세가 10%와 다름, 흐려서 불확실, **중복**(같은 승인번호, 같은 날·같은 금액·같은 사업자번호나 상호나 카드 — 같은 영수증을 두 번 찍은 것, 카드 문자와 영수증이 같이 들어온 것).
- **빈 금액 채우기**: 합계만 있으면 부가세 10%로 나눠 계산(추정이라고 표시), 계산서(면세)는 부가세 0, 둘이 있으면 나머지 하나를 계산.
- **계정과목 짐작**: 상호·품목 낱말로 복리후생비(식대), 여비교통비, 차량유지비, 통신비, 소모품비, 도서인쇄비, 지급수수료, 수도광열비, 비품, 광고선전비, 교육훈련비. 짐작했다고 표시한다.
- **엑셀 장부**: '장부'(틀림 빨강·확인 노랑, 합계 줄은 계산식, 종류 칸 고르기 목록, 거르기 단추, 인쇄하면 가로 한 장 폭), '월별', '거래처별', '계정과목별', '부가세'(세금계산서·계산서·카드/현금영수증·그 밖 증빙별 합계), '확인 필요'(문제와 짐작한 것 모음).
- **이어 쓰기**: `--into 지난장부.xlsx` 로 지난달 장부에 새 거래를 더하고, 이미 있는 거래는 다시 넣지 않는다.

**못 하는 것**
- 도구가 사진 속 글자를 스스로 읽지는 않는다 — 내가 그림을 보고 읽는다. 그래서 한 번에 아주 많은 사진(수백 장)은 오래 걸린다. 50장이 넘으면 나눠서 하자고 말한다.
- 손글씨 간이영수증, 많이 구겨지거나 잘린 영수증은 틀리게 읽을 수 있다 → `확신: 낮음`.
- 홈택스·카드사에서 자료를 직접 받아 오기(로그인이 필요해서 하지 않는다). 사용자가 내려받은 엑셀·PDF는 읽을 수 있다.
- 세금 계산·신고서 작성, 공제 판단.
- *아이폰 HEIC 사진은 pillow-heif 가 있어야 한다(없으면 알려 준다).

## 2. 일하는 순서

1. **준비** (채팅마다 한 번)
   ```
   pip install -q --break-system-packages openpyxl pypdf pypdfium2 pillow
   L=$(find / -name rledger.py -path '*receipt-ledger*' 2>/dev/null | head -1); echo $L
   ```
2. **파일 받기**: 채팅에 올린 파일이나 연결된 PC 폴더. 원본은 작업 폴더에 복사해서 쓴다.
3. **읽을 준비**:
   ```
   python3 $L prep 받은폴더/ --out 작업
   ```
   `작업/작업목록.md` 에 파일마다 볼 그림과 할 일이, `작업/입력.json` 에 초안이 생긴다.
4. **내가 읽기**: 작업목록 순서대로 그림을 Read로 보고 `입력.json` 의 같은 번호를 채운다.
   - 칸: `종류`(영수증·카드영수증·현금영수증·세금계산서·계산서·거래명세서·카드문자), `날짜`(2026-10-25), `상호`(파는 쪽), `사업자번호`(파는 쪽 — 세금계산서는 '공급자' 칸), `품목`(짧게), `공급가액`, `부가세`, `합계`(숫자만), `결제수단`(카드·현금·계좌이체), `카드끝4자리`, `승인번호`, `계정과목`(모르면 비움 — 도구가 짐작), `메모`, `확신`(높음·보통·낮음).
   - 흐린 사진은 `_선명` 그림을 먼저 본다. 그래도 안 보이면 그 부분을 잘라 2~3배로 키운 그림을 만들어(Pillow crop·resize) 다시 보거나, 칸을 비우고 `확신: 낮음`.
   - **영수증은 줄이 비뚤어 금액이 이름표 한 줄 위·아래에 찍혀 있을 수 있다.** 공급가액+부가세=합계가 되는지 머릿속으로 맞춰 본다.
   - 글자 있는 PDF의 초안 값도 그림과 견준다(특히 상호·사업자번호가 '공급받는자' 것으로 잘못 들어가지 않았는지).
5. **검사**:
   ```
   python3 $L check 작업/입력.json
   ```
   ✗(틀림)은 그림을 다시 보고 고친다. 사업자번호 검사 숫자 틀림은 대부분 잘못 읽은 것 — 다시 보고 그래도 그렇게 적혀 있으면 그대로 두고 사용자에게 알린다. 중복(!)은 목록으로 보여 주고 뺄지 묻는다.
6. **장부 만들기**:
   ```
   python3 $L build 작업/입력.json --out 장부_2026-10.xlsx [--drop-dupes] [--into 지난장부.xlsx]
   ```
7. **결과 주기**: 엑셀을 SendUserFile로 주고 한두 줄로 — "9건, 합계 1,927,000원. 7번 주유 영수증의 사업자번호가 이상하니 원본을 봐 주세요."

**카드 문자만 있을 때**: 문자를 .txt로 받아 `sms 문자.txt --out 작업/입력.json` → 검사 → 장부. 문자에는 사업자번호·품목·부가세가 없어서 합계만으로 나눈 값은 추정이라고 말한다.
